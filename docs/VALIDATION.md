# 当前插件验收

开发验收直接引用本机真实 YMM4 SDK，调用插件的 `IVoicePlugin` / `IVoiceSpeaker`。
实际音频由本机正版 A.I.VOICE2 Editor 2.13.0 中的协议2 DLL 生成，没有 mock 合成、Python 服务或重做引擎。

机器记录为 `evidence/acceptance.json`：**57 项通过**，包括8个声库的真实 WAV、无扩展名宿主路径、
重复合成一致性、百分比参数、风格混合、项目参数克隆、嵌套撤销传播、切换声库的参数迁移、
原厂错误恢复、输出保护、定向取消、超时停止确认、8个并发调用的串行执行以及格式和哈希校验。
YMM4 SDK 本身会按 Range 约束处理越界参数，验收以实际宿主行为为准。

`evidence/cache-restart.json` 验证独立验收宿主进程重启后声库缓存仍可用。
验收宿主的设置、临时 EXE 和 SDK 依赖只位于 `build/acceptance`，不进入发行包，也不是插件运行依赖。

WPF 设置控件在 STA 线程构造并离屏绘制，条件风格滑块按元数据正确显示与隐藏。
该检查证明控件可创建、绑定和布局，不等于已经在实际 YMM4 窗口逐项点击验收。
图像和真实 WAV 位于 `acceptance.json` 指定的 `run_directory`。

实际 YMM4 的正常启动、插件模块路径、安装文件哈希及状态单独记录在 `evidence/ymm4-runtime.json`。
不能把 DLL 复制成功或静态元数据检查当作宿主窗口已显示声库和台词生成按钮已实测。

本次原版 YMM4 正常启动后已实际加载安装目录中的 `AIVoice2Bridge.YMM4.dll`，
主窗口正常响应，并注册了插件设置文件。宿主内角色选择及时间线点击生成尚未逐项操作验收。
首次使用需要在本插件设置页点击“更新声库”，将 Editor 的声库列表载入该 YMM4 实例。

本机8个批量任务累计33.8293秒音频，墙钟6.2047秒，RTF约0.1834；该数字仅对应验收文本与本机。

## 适用范围

目标版本为本机 YMM4 4.56.1.1 / Windows x64 / .NET10 与原版 Editor 2.13.0 / Bridge协议2。
未验证其他宿主版本、跨语言自然度、逐音素时序或数天连续运行。
当前宿主语音接口没有 CancellationToken；直接接口验收的取消测试使用插件提供的显式重载，
不代表宿主取消按钮能透传取消。普通 YMM4 调用仍受配置的合成超时与定向任务清理保护。
